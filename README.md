# 111EcosystemVR — 台灣生態系 VR 教育遊戲

## 專案簡介

本專案為台灣生態教育 VR 互動遊戲，以沉浸式虛擬實境方式，帶領學習者探索台灣的生物多樣性、棲地環境與生態保育議題。

- **Unity 版本：** 2021.3.13f1
- **支援平台：** VR（HTC Vive Wave / Oculus Android）、PC（滑鼠鍵盤）
- **開發語言：** C#
- **主要受眾：** 中小學生

---

## 各章關卡詳細說明

### Chapter 1 — 生物多樣性

**場景環境：** 草原 + 河流
**學習目標：** 認識生物多樣性的概念，分辨不同棲地的代表動物

**玩法：**
1. 場景中會出現多種動物（企鵝、獅子、斑馬、熊、海豹等）
2. 玩家需將動物拖曳/引導至正確的棲地區域
3. 系統記錄放置正確（LiveNum）與錯誤（DeadNum）的數量
4. 全數正確放置後過關

---

### Chapter 2 — 台灣多樣化環境

**場景環境：** 多種台灣地形（森林、海岸、高山、濕地）
**學習目標：** 認識台灣各種自然環境與其生態特色

**玩法：**
1. 玩家在環境中自由移動探索
2. 觀察不同地形的代表景觀與物種
3. 完成環境識別互動任務

---

### Chapter 3 — 生物生存適應

**場景環境：** 多樣化生態場景
**學習目標：** 理解生物如何適應特定環境

**玩法：**
1. 觀察場景中的生物行為與特徵
2. 完成配對或問答互動
3. 了解形態、行為、生理各面向的適應策略

---

### Chapter 4 — 外來入侵種對台灣的影響

**場景環境：** 格狀植物田

**學習目標：** 認識外來入侵植物（大花咸豐草、小花蔓澤蘭）對台灣生態的危害

**玩法：**
1. 場景呈現一片格狀植物田，其中混雜入侵種花朵
2. 玩家用控制器/滑鼠瞄準並點擊移除入侵種花朵
3. 兩種入侵植物分別有不同分數
4. 清除全部入侵種後過關，並有粒子特效與音效回饋

---

### Chapter 5 — 候鳥遷徙

**場景環境：** 水域 + 飛行天空路徑

**學習目標：** 體驗候鳥遷徙過程，了解其生存挑戰

**玩法（共 8 步驟）：**
1. 玩家扮演候鳥，以游泳/飛行方式移動
2. 需在水域中吃到至少 3 條魚補充體力
3. 找到遷徙路徑的起訖點
4. 完成整段遷徙旅程
5. 系統按步驟記錄進度並回傳伺服器

**特殊互動：** 扇翅動作偵測（FlappingCheck）

---

### Chapter 6 — 淺山生態與石虎

**場景環境：** 山區道路與森林

**學習目標：** 認識台灣石虎的生存困境，了解路殺問題

**玩法：**
1. 玩家扮演石虎在山區道路行走
2. 需閃避往來的車輛（碰到即死亡）
3. 可收集路邊的檸檬
4. 與雞隻互動
5. 通過邊界觸發點進入下一區域
6. 死亡後系統重新生成（Respawn），有閃爍視覺效果

## 系統架構

### 核心腳本（Assets/Scripts/）

| 腳本 | 功能 |
|------|------|
| `GlobalSet.cs` | 全域狀態管理（學生ID、關卡ID、VR/PC模式、手部追蹤） |
| `WebPhp.cs` | 伺服器通訊，記錄學習行為至 PHP 後端 |
| `VRControl.cs` | VR 控制器輸入處理 |
| `MouseControl.cs` | PC 滑鼠射線互動 |
| `LoadScene.cs` | 場景切換管理 |
| `DeepLinkHandler.cs` | 支援外部連結直接開啟指定章節 |
| `NetWorkMode.cs` | 切換本地/遠端記錄模式 |
| `ScreenRecord.cs` | 截圖並透過 FTP 上傳 |
| `CameraHeight.cs` | VR 鏡頭高度校正 |

### 學習行為記錄流程

```
學生登入（輸入學號）
    ↓
選擇章節 → 記錄進入時間 (EntryTime)
    ↓
遊戲中各操作事件 → 傳送至 Action.php
    ↓
離開章節 → 記錄退出時間 (ExitTime) → 傳送至 LevelInf.php
    ↓
本地備份：Application.persistentDataPath/record.txt
```

### 平台自動偵測

- **Android（Oculus）：** 自動切換為 VR 模式
- **Windows：** 自動切換為 PC 鍵盤滑鼠模式
